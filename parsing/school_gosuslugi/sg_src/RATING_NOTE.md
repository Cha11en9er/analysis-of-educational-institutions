# Памятка: как считается рейтинг школ

Данные рейтинга находятся в файле `sd_2_stage_gosuslugi_infrastucture_output_extract.json`.

## Какие факторы участвуют

Для каждой школы рассчитываются 6 факторов (с равными долями):

1. `academics_ege_2025` — нормализованный средний балл ЕГЭ за 2025 год.
2. `academics_vuz_2025` — нормализованный процент поступления в ВУЗ за 2025 год.
3. `olympiads` — нормализованный показатель олимпиад (с учетом уровня этапа).
4. `reviews` — средняя пользовательская оценка (Яндекс/2ГИС), приведенная к шкале 0..1.
5. `infrastructure` — нормализованный показатель инфраструктуры.
6. `specialization` — наличие профильного обучения:
   - `1.0`, если есть профиль;
   - `0.0`, если `без специализации`.

`study_type` (начальная/средняя/старшая/полная) пока не участвует, так как поле еще не заполнено.

## Как извлекаются данные

- ЕГЭ: берется только запись `EGE`, где явно указан `2025` (например: `62,5 - ... в 2025 году`).
- ВУЗ: аналогично, только запись `VUZ` с `2025`.
- Олимпиады: из массива `Olympiads` достается число призеров и взвешивается по уровню этапа:
  - школьный: `0.25`
  - муниципальный: `0.50`
  - региональный: `0.75`
  - заключительный/федеральный: `1.00`
- Упоминание "всероссийской" учитывается как максимальный уровень олимпиадной значимости.
- Инфраструктура: используется количество пунктов в `infrastucture` + спортивные признаки (`has_sports_complex`, `has_pool`, `has_stadium`, `has_sports_ground`).

## Нормализация

Числовые факторы нормализуются по min-max в диапазон `0..1`:

`norm = (x - min) / (max - min)`

Если для фактора нет значения, он временно заполняется нейтральным `0.5` (чтобы рейтинг считался у всех школ).

## Итоговый рейтинг

1. Считается среднее арифметическое 6 факторов (равные доли).
2. Добавляется небольшой штраф за неполноту данных:

`penalty = missing_factors_count * 0.012`

3. Финальный рейтинг:

`rating_overall_equal_weights = max(0, base_average - penalty) * 100`

Таким образом:
- рейтинг есть у каждой школы;
- при прочих равных школа с полными данными будет немного выше.

## Поля в итоговом JSON

Для каждой школы дополнительно сохраняются:

- `specialization_extract`
- `ege_avg_score_2025`
- `olympiad_winners_count_raw`
- `olympiad_winners_weighted`
- `rating_components`
- `rating_completeness`
- `rating_missing_factors_count`
- `rating_missing_penalty`
- `rating_overall_equal_weights`
- `rating_rank`
- `rating_method`
