# Гайд: добавление данных о школах нового города в УчГрад

Файл-инструкция для агента (или человека). Выполните по шагам; всё фиксируйте в
`roadmap/ДД.ММ.ГГ/summary.md` дня. Пример-эталон: Энгельс (`roadmap/01.11.26/engels/`).

## Принципы (не нарушать)

1. **Только официальные источники.** Тип организации — категория каталога РЦОКО и
   официальное полное наименование (тип по ФЗ-273 записан в самом названии:
   «дошкольного образования», «общеобразовательная школа», «спортивной подготовки»,
   «высшего образования»). Никаких придуманных классификаций по слухам/похожести.
2. **Полный адрес при геокодировании**: «Россия, <область>, <город/район>, <улица>, <дом>».
   Без города геокодер вернёт чужой город. Кэш обязателен (ok не отправлять повторно).
3. **Лимит Яндекс-геокодера 1000/сутки** (превышение = блокировка ключа на сутки).
   Бюджет прогона ≤850. Журнал расхода: `sa.geocode_log`. Ключ ограничен по Referrer
   `https://uchgrad.ru/` — запросы с сервера обязаны передавать этот заголовок.
4. **Формула rating_total** — только через `school_data/prepare_final_data.py`
   (функция compute_rating_total). Отсутствующие компоненты = NULL (не штрафуют).
5. **Тексты на сайте** — по-человечески, без длинных тире и символов-разделителей
   (правило `.cursor/rules/text-style.mdc`).
6. Рестартить только `uchgrad-api`; чужие сайты/сервисы сервера не трогать.

## Шаг 1. Реестр школ города

1. Источник-якорь: каталог РЦОКО `sarrcoko.ru/catalog/?mup=<код города>` (коды АТЕ
   из каталога; Энгельс = mup 241 + районы). Собирается скриптом
   `roadmap/30.10.26/engels/collect_catalog.py` (запуск на RU-сервере uchgrad-vps;
   с обычной машины сайт отдаёт 403 и капчу).
2. Сверить с официальным списком комитета образования города (сайт администрации,
   раздел «Образование») — РЦОКО-каталог может не содержать часть школ (частные
   Школа «Патриот» и «Прогимназия Идеал» в РЦОКО отсутствуют).
3. Для каждой школы зафиксировать: код ОО, полное/краткое имя, адрес, телефон,
   сайт (Госуслуги-карточка), директора.
4. Сайты школ города обычно на доменах `*-r64.gosweb.gosuslugi.ru` — найти по
   поисковой выдаче «{N} школа {город} госуслуги».

## Шаг 2. Карточки Яндекс.Карт и 2ГИС

- **Яндекс.Карты — работает SSR-поиск**: `GET https://yandex.ru/maps/{geoId}/{city}/search/{имя школы}`
  отдаёт HTML с org-ссылками. Скрипт: `roadmap/01.11.26/engels/ym_find.py`.
  geoId города найти по выдаче (Энгельс = 11147). Первый org-матч = карточка школы.
- **Рейтинг Яндекса — из той же SSR org-страницы**: `ratingValue` + число оценок
  (`roadmap/01.11.26/engels/ym_ratings.py`). 44/45 школ получено за ~1 минуту.
- **2ГИС**: API/Search API недоступны; Selenium-парсер заблокирован антиботом
  (страница-заглушка). Рабочий способ — **Playwright с channel='chrome'** и свежим UA:
  `roadmap/01.11.26/engels/gis_firms_playwright.py` (поиск по имени школы → первый
  firm-линк; 45/48). Прямые firm-страницы в headless отдают заглушку — рейтинги 2ГИС
  собирать headed-прогоном у владельца на ПК или позже.
- Проверка пропусков: сравнить список школ города с выдачей 2ГИС/Яндекса — если школа
  из официального списка не нашлась (пример: СОШ «Патриот»), искать отдельно
  («{имя школы} {город} госуслуги») и добавлять вручную с synthetic school_id.

## Шаг 3. Внесение в БД

1. Модель: `sa.school` — school_id = 100000 + код ОО (не пересекается с Саратовом),
   city = город, ownership (public/private — частные ЧОУ/АНО/НОУ/религиозные),
   координаты, ссылки. Ссылки — в `sa.link` (link_yandex, link_2gis, link_gosuslugi),
   НЕ в sa.school. Рейтинги — в `sa.rating` (rating_yandex).
2. Загрузчик: `db/db_src/db_insert/db_load_city_schools.py` (вход `city_schools.json`).
3. **Внимание**: `TRUNCATE sa.school CASCADE` сносит `sa.school_address` — после любой
   перезагрузки школ запускать `db_load_catchment.py`.

## Шаг 4. Показатели (Госуслуги)

1. Парсер: `parsing/school_gosuslugi/sg_src/sg_main.py input.json output.json`
   (Selenium, headless). Вход — JSON с id/name/address/link_gosuslugi.
2. Тест на 1–3 школах перед массовым прогоном (шаблоны страниц меняются: обновляйте
   User-Agent на фактическую версию Chrome и следите за классификацией KPI:
   «средний балл ЕГЭ» ≠ «высший балл ЕГЭ» — баг уже ловили, фикс в sg_main).
3. Пересчёт рейтинга: сырьё → числовые поля (rating_ege, ege_year,
   university_admission_percent+year, olympiad_winners_count) → compute_rating_total.
   Обновление БД: UPDATE sa.school (rating_*) + sa.rating (rating_yandex) —
   rating_yandex живёт в sa.rating, не в sa.school.

## Шаг 5. Геокодирование домов (закрепление)

1. Найти документ о закреплении: сайт комитета образования города / сайты школ,
   раздел «Документы», по запросу «закрепление микрорайонов {город} {год} приказ»
   (Энгельс: приказ 136-од от 11.03.2026, PDF-скан).
2. Транскрибировать в CSV: `city, district, street, houses_spec, school`
   (`roadmap/01.11.26/engels/attachment_city_geo.csv`). Для сёл часто достаточно
   «школа → населённые пункты» (прил. 3).
3. Импорт: `db_load_catchment.py` (address + school_address, 0 API — берёт уже
   геокодированные из кэша; новые идут в pending).
4. Геокод pending: `geocoding/scripts/daily_geocode.py --limit 900` (или cron 04:10).
   Журнал и лимиты — см. `.cursor/rules/geocoding.mdc`.
5. Полный прогон новых городов ≈ 900/день; каждый день cron докладывает сам.

## Шаг 6. UI

- Город появляется в селекторе автоматически (city из БД). Список «Школы» для города
  читает sa.school по city. Институции (садики/вузы/иные) — `/api/institutions?group=&city=`.
- Проверки перед сдачей: селектор города, баллы в списке, карточка школы,
  зоны прикрепления, отсутствие дублей школ в институциях (group=school скрыт в API).
