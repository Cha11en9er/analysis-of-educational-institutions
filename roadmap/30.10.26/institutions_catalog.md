## Что есть у каждой карточки в каталоге РЦОКО

Код ОО (6 цифр, в ribbon), краткое и полное имя, ФИО директора, телефон (tel:),
сайт, адрес (индекс, город, улица, дом), документы по годам:
- аналитические отчёты `.doc` (2021–2023): `/razbor_catalog/oyo/YYYY/КОО/…`
- статистические отчёты `.pdf` (2024–2025): там же
- **ВПР по классам `.xls/xlsx`** (2020–2024): `/razbor_catalog/vpr/…` — школьный уровень
- «Индекс качества общего образования» — динамические диаграммы `/reports_rgi/?year=…&oo=…`

## API индекса качества (открытый, без ключа)

`GET /reports_rgi/ajax_chart.php?proc=get_data&type_chart=1&get_data_type=oo
&get_data_year=2025&get_data_select=<код ОО>&filter=<критерии через ~>&get_data_step=20&get_data_offset=0`
→ JSON: labels=[«Сар.обл», mup000, oo], datasets=[{label: критерий, tooltips: описание, data: [3 значения]}].

Справочник 25 критериев: `sarrcoko/rcoko_criteria.json`. Ключевые:
- 1.1.1 — доля выпускников 11 кл., не набравших минимум ЕГЭ (обязательные) — **красный флаг школы**
- 1.1.6/1.1.7 — первичный балл нижней границы 25% лучших (русский/математика) — сила верхней прослойки
- 1.1.8–1.1.11 — ОГЭ аналогично; 1.1.14–1.1.17 — ВПР 4 кл.; 1.2.x — выбор предметов (профильность)

**Среднего балла ЕГЭ в индексе нет** — сверка наших ege_average_score возможна только
косвенно (у наших топ-10 1.1.1=0 в 2025 — противоречий не видно; прямая проверка —
через ВПР/аналитические .doc файлы, не делалось).

## Блокер геокода учреждений

Ключ `YANDEX_API_KEY` в .env — **JS-карты**; HTTP-геокодер отвечает 403 Invalid api key.
Nominatim (OSM) не знает дома Саратова: 66/194 ok. Скрипт
`geocoding/scripts/geocode_institutions.py --provider yandex` готов — нужно от владельца:
создать в кабинете developer.tech.yandex.ru ключ типа **HTTP Геокодер** и добавить в .env
(например `YANDEX_GEOCODER_API_KEY=...`; скрипт переключить на чтение этого имени).
После этого прогнать `--retry-failed` — покрытие станет полным.
