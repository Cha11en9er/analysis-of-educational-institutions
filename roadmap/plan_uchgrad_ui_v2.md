## Контекст (что уже есть)

- Прод: https://uchgrad.ru (nginx → UI/build + API DATA_SOURCE=db, PostgreSQL schema `sa`).
- Локальный запуск: API `uvicorn api.main:app --reload` из корня; UI `cd UI && npm start`.
- Эталон дизайна (с чего писали реплит): https://school-insights-aapotapov.replit.app/

- Данные школ: `GET /api/schools/map` (список для карты, уже с rating_yandex/2gis),
  `GET /api/schools/{id}` (детально), `GET /api/schools/{id}/reviews/topics` (темы по датам).

## Этап 0 — бэкенд: недостающие поля (ОБЯЗАТЕЛЬНО до UI-этапов)

Проблема: в `sa.school` нет rating_total, ЕГЭ, олимпиад и т.п. — они только в
`school_data/final_school_data.json`. API в db-режиме их не отдаёт.

1. `db/db_src/db_create/create_script.sql`: ALTER для `sa.school` — добавить колонки:
   `rating_total NUMERIC(6,1)`, `ege_average_score NUMERIC(4,1)`, `ege_year INT`,
   `university_admission_percent NUMERIC(5,1)`, `olympiad_winners_count INT`,
   `top_tags JSONB`, `administrative_district TEXT`,
   `rating_ege NUMERIC, rating_olympiads NUMERIC, rating_teachers NUMERIC, rating_mto NUMERIC,
   rating_psychological_climate NUMERIC, rating_sports_infrastructure NUMERIC`.
   (Файл — полный DDL: добавить колонки в CREATE TABLE, они применятся только к новой базе;
   для прода написать отдельный `ALTER TABLE ... ADD COLUMN IF NOT EXISTS ...` в конце того же файла
   и выполнить на сервере через psql.)
2. `db/db_src/db_insert/db_load_final.py`: в `load_school_rows()` добавить эти поля в
   INSERT (значения уже есть в final_school_data.json — ключи те же, с snake_case).
3. `api/main.py` db-ветка `GET /api/schools/map`: добавить в SELECT и в ответ
   `rating_total`, `ege_average_score`. db-ветка `GET /api/schools/{id}`: добавить все новые поля.
4. Прогнать на сервере: `git pull && psql ... -f create_script.sql && .venv/bin/python db/db_src/db_insert/db_load_final.py && systemctl restart uchgrad-api`.

Приёмка 0: `curl https://uchgrad.ru/api/schools/map | python -m json.tool | grep rating_total` — не пусто;

2. Под фильтрами — ВИРТУАЛЬНЫЙ список школ, отсортированный по `rating_total` DESC:

4. Сортировка: селект «По итоговому рейтингу / По ЕГЭ / По рейтингу Яндекса / По году постройки»
