## Открытия/баги дня
1. **ymaps3 setLocation не принимает easing-строку** («Unexpected timing function used») — исключение роняло весь React-рут (белый экран). Убрал параметр, оставил duration.
2. **UI/build не в git** — деплой только tar+scp (git pull билд не обновляет).
3. **REACT_APP_API_URL**: сборка без UI/.env ломала прод (звонила на localhost:8000). Сделан умный дефолт: localhost → :8000, иначе same-origin — .env больше не нужен.
4. **rating_ege — это сам балл ЕГЭ (0–100)**, остальные rating_* — доли 0..1; нормализация разная (иначе «8700%»).
